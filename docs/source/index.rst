Taksh
=====

Taksh (formerly QuantsMind-LLM) is a **sovereign, from-scratch coding LLM** for
Python, JavaScript/TypeScript and software engineering, with finance as an early
application vertical.

Published from ``docs/source`` RST via GitHub Pages on every ``main`` merge.
Rule book: ``docs/RULEBOOK.md``. Owner / sole contributor: ``ajit-ai``.
