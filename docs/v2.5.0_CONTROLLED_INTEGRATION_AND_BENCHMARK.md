# Taksh v2.5.0-C3 — Controlled Integration and Independent Python Benchmark

Date: 2026-10-23  
Status: **integrated experimentally; model capability evidence remains negative**

## Integration architecture

- `serving/local_inference.py::generate_ids` now returns `raw_text` and a structured `repair` diagnostic containing enabled/applied/status/reason/mapping/changed/raw_preserved.
- Repair failure preserves the raw completion and reports `repair_failed`.
- `binding_repair=False` remains the independently selectable baseline.
- `PythonCodeGenerator` preserves the off state from `model_identity["binding_repair"]`.
- Repair is deterministic, conservative, and applies only to the requested body.
- All frozen suites remain unmodified and separately hashed:
  - AD-1 SHA-256 `a5bf9406…`
  - C1 SHA-256 `961936f8…`

## Decisions

### Integration decision

**ACCEPT FOR CONTINUED EXPERIMENTAL INTEGRATION.**

The repair is now configurable, observable, default-off capable, failure-safe and regression-safe across the frozen gates.

### Model capability decision

**NOT DEMONSTRATED.**

The held-out set exposed a capability gap: despite 24 syntactically valid outputs, no functional fixture passed. Binding repair is a narrow post-processing safeguard, not a Python coding capability.

## Defects and blockers

- The S2 checkpoint frequently produces wrong operations and malformed bodies.
- Conservative repair correctly abstains on most malformed output.
- No improvement was demonstrated on the broader held-out benchmark.
- No multilingual training corpus, approved 113M/S4 checkpoint or training authorization exists.
- No production, weights or dataset redistribution authorization exists.
