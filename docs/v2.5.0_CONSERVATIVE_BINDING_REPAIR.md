# Taksh v2.5.0-C2 — Conservative Binding Repair

Date: 2026-10-23  
Status: **conservative implementation completed; not a capability or release claim**

## Policy changes

The binding repair now fails closed:

- Repairs only when there is exactly one unbound generated-name and exactly one unused requested parameter.
- Multi-candidate and multi-unused mappings are left unchanged.
- Whole-function completions are never repaired.
- Nested functions and lambdas are never repaired.
- Imports, global/nonlocal declarations, unknown calls, dunder attributes and non-allowlisted methods are never repaired.
- Completions with no return statement are left unchanged.
- Source strings, comments and formatted output are not regex-rewritten; `tokenize` is used for the single approved mapping.
- Abstention is observable through `repair_completion_info()` with statuses such as `abstained_ambiguous`, `abstained_unsafe` and `unchanged_no_candidates`.

The repair does not infer semantic intent from model confidence and does not execute generated code.
