- No raw-pass case regressed.

- Several arity-matching wrong programs were renamed without becoming semantically correct (`Q-mapping-000`, `Q-loop-000`, `Q-nested-002`); these are not acceptable as execution-ready code.
- Functional fixtures demonstrate executability on approved cases, not general correctness; single-input fixtures can pass an accidentally compatible wrong program (`Q-sub-000`, `Q-mul-000`) and are not semantic certification.
- No arbitrary generated code was executed. Only `execution_safe=true` pure fixtures were run, with a restricted AST gate, isolated Python process and 2-second timeout.

## Decision and safeguards

**CONDITIONALLY QUALIFIED** because the repair produced measured gains beyond AD-1 with zero observed regressions, but it fixes names rather than intent and leaves most model errors intact.

Required before integration:

1. Keep AD-1 and this independent suite frozen; rerun after every change.
2. Require zero regressions on `parse`, `binding`, `exact` and approved fixtures.
3. Execution only for whitelisted pure functions with multiple independent tests.
4. Report binding-only wins separately from functional/runtime wins.
5. Do not use repaired output as evidence of semantic correctness or use it to bypass human review.
6. Do not promote Taksh or any external model to production from these results.
