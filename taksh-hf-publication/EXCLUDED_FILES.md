# Excluded-File Inventory — TAKSH v1.4.1 ALPHA Hugging Face Publication

This document lists files and directories from the source repository that are
**excluded** from the Hugging Face publication directory, with reasons. No
source-code change, fixture change, or training-data change was made.

## Excluded by license/provenance (NOT CLEARED for distribution)

| Path | Reason |
|---|---|
| `artifacts/taksh-s2-experimental/taksh-s2.pt` | Checkpoint weights not cleared: `training_data_license: not cleared`, `model_weights_license: not cleared`, `distribution_approved: false` |
| `artifacts/taksh-s2-experimental/tokenizer/qm_code_bpe_v0.json` | Tokenizer vocab derived from training data whose license is not cleared |
| `artifacts/taksh-s2-experimental/*` | Entire staged experimental artifact is `NOT APPROVED FOR DISTRIBUTION` |
| `runs/*` | Training checkpoints and run artifacts — not cleared, not part of source release |
| `data/*` (data artifacts) | Training corpora and token bins — license not cleared |
| `data/code_corpus_v0.jsonl`, `data/code_corpus_v0.tokens.bin` | Training data — license not cleared |
| `data/internal_corpus_v0.tokens.bin` | Internal training data — not cleared |
| `data/code_sft_v0.jsonl`, `data/code_sft_v0.quarantine.json` | Quarantined SFT corpus — not cleared |

## Excluded by build/artifact policy (not source code)

| Path | Reason |
|---|---|
| `dist/*` | Built wheel/sdist — build artifacts, regenerated at release time |
| `build/*` | Intermediate build directory — regenerated at release time |
| `taksh.egg-info/` | Editable-install metadata — regenerated at install time |
| `__pycache__/` | Python bytecode cache — regenerated at import time |
| `.pytest_cache/` | Pytest cache — regenerated at test time |
| `.venv/`, `venv/` | Virtual environments — not part of source |
| `docs/build/`, `docs/_build/` | Sphinx build output — regenerated at docs build time |
| `reports/release-evidence/` | Release evidence from prior run — regenerated by `prepare_release.py` |

## Excluded by Git policy (not part of source tree)

| Path | Reason |
|---|---|
| `.git/` | Git metadata — not part of source distribution |
| `.github/workflows/` | CI workflows — GitHub-specific, not part of PyPI/HF package |
| `.gitignore` | Git-specific ignore file; HF uses `.gitattributes` instead |
| `*.key`, `*.pem`, `.env`, `secrets/` | Secrets and credentials — never distributed |

## Excluded by scope (not needed for HF model repo)

| Path | Reason |
|---|---|
| `TAKSH_V*.md` (prior campaign reports, except v1.4.1) | Historical reports; only `TAKSH_V141_FINAL_QUALIFICATION_REPORT.md` is included as current qualification evidence |
| `kaggle_pilot.ipynb`, `KAGGLE_PILOT_GUIDE.md` | Kaggle-specific pilot material, not part of core package |
| `reports/` (except release-evidence) | Historical experiment reports — not part of source release |

## Files INCLUDED in the publication

| Category | Files |
|---|---|
| Source code | `taksh/`, `serving/`, `evaluation/`, `tokenizer/` (code only), `training/`, `configs/`, `data/` (pipeline code only), `scripts/`, `tests/` |
| Package metadata | `pyproject.toml`, `requirements.txt`, `MANIFEST.in`, `pytest.ini`, `conftest.py` |
| License/docs | `LICENSE`, `NOTICE`, `CHANGELOG.md`, `CONTRIBUTING.md`, `README.md` (HF model card) |
| Qualification evidence | `TAKSH_V141_FINAL_QUALIFICATION_REPORT.md` |
| Publication metadata | `.gitattributes`, `upload_manifest.json`, `EXCLUDED_FILES.md`, `LICENSE_PROVENANCE.md` |
