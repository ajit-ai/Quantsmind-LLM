# Contributing — Quantsmind-LLM (solo project)

Owner / sole contributor: **[@ajit-ai](https://github.com/ajit-ai)**.

- No new collaborators are added. Do not request access.
- Do not push directly to `main` or `develop`.
- External suggestions: open an Issue. Code PRs from non-owner accounts will be closed.
- Owner flow: `feat/<phase>-<topic>` → PR → `develop` → release PR → `main`.
- Every PR must keep `python -m pytest tests -q` green and follow `docs/RULEBOOK.md`.
